# Viking: Endless Arena - Balance Updates

This repository contains balance updates and bug fixes for Viking: Endless Arena.

## Changes
- **Berserk Mode**: Increased stun potential against all enemies.
- **Archers**: Reduced health and adjusted AI to be less evasive during attacks.
- **Avalanche Breaker**: Fixed the direction of the ground indicator.
- **Chain of the Fallen**: Replaced teleportation with smooth movement and added a significant stun.
- **Boss - Yrsa Wolf-Eye (Huntress)**: Reduced health and fixed "magic" tracking on her snipe.
- **Boss - Hakon Flame-Beard**: Fixed movement during the "Find the Gap" cage phase.
- **Visuals**: Enhanced boss attack indicators for better clarity.
